# Jarred Ward · Portfolio

**Live site:** www.jarredward.tech

My personal portfolio site, built to showcase my background and current work in vulnerability management and governance, risk, and compliance (GRC).

## 🧭 What's on it

- **My background**: career timeline, certifications, and how I got into cybersecurity.
- **An animated portrait**: my headshot rendered as thousands of individual particles that assemble on load and react to your cursor.
- **My project work**, including live links to my GitHub projects, which stay up to date automatically.
- **A contact form** that emails me directly, with no third-party form service involved.
- **Light and dark themes**, saved for your next visit.

## 🛠️ How it's built

A custom site, not a template: React and TypeScript on the front end, hosted on Cloudflare. Built with the same security mindset I bring to my GRC work: strict security headers, no unnecessary third-party scripts, and everything on the contact form re-checked server-side.

Want the technical breakdown, covering architecture, build pipeline, and setup instructions? See [DEVELOPMENT.md](DEVELOPMENT.md).
